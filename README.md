# FOODWISE

FOODWISE is a Kenya food-price and household basket-scenario prototype. It combines public WFP market-price observations with KNBS inflation context and provides an interactive Streamlit dashboard.

## Main project

See [`foodwise_project/README.md`](foodwise_project/README.md) for setup, data sources, limitations, and test instructions.

The runnable dashboard is in [`foodwise_project/`](foodwise_project/). Its presentation and one-page handout are in [`foodwise_project/presentation/`](foodwise_project/presentation/).

## Companion showcase materials

[`FOODWISE_Tonight/`](FOODWISE_Tonight/) contains the initial problem notes, prototype workbook, charts, and showcase materials.

The bundled datasets are public-source files. The dashboard uses local copies and does not stream live data.
